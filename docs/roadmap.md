# Roadmap

Each phase is a GitHub milestone, and each item an issue. Estimates assume part-time work.

| Milestone | Goal | Estimate |
| --- | --- | --- |
| Phase 0: Spike | A 60 MP M11 DNG opens and an exposure slider responds in real time, local and on the NAS | Done |
| Phase 1: Browser panels | Folders panel, thumbnails, star filter from XMP, filmstrip | Done |
| Phase 2: Basic panel | Lightroom's Basic panel minus Texture and Clarity; Dehaze; histogram; crop and straighten; undo | Done except Dehaze (#26) |
| Phase 3: Curves and LUTs | Tone curve per channel; `.cube` LUTs with previews and strength; inspector cards | Done |
| Phase 4: Edit comfortably | Zoom to 100% and beyond; save ratings and flags to XMP sidecars; sharpening and noise reduction; Texture and Clarity; before/after; auto and eyedropper white balance; Vignette | 3 weekends |
| Phase 5: Geometry | Lens profile corrections, manual distortion and lens vignetting, manual and automatic perspective, the camera's own crop | 2–3 weekends |
| Phase 6: Color | HSL color mixer, black and white | 2 weekends |
| Phase 7: Many photos | Copy and paste settings, multi-select, context menus, instant previews, history, filters, relinking | 2 weekends |
| Phase 8: Export | JPEG, HEIC and TIFF export; signing and notarization | 1 weekend |
| Effects | Film grain, halation and bloom; scope to be decided | — |
| v1.2 | Masks as layers: gradients, Vision subject and person masks, brush | — |
| Later | Presets, appearance setting, iPad and iPhone app | — |

Not planned: healing, a catalog, cloud sync.
