# Roadmap

Each phase is a GitHub milestone, and each item an issue. Estimates assume part-time work.

| Milestone | Goal | Estimate |
| --- | --- | --- |
| Phase 0: Spike | A 60 MP M11 DNG opens and an exposure slider responds in real time, local and on the NAS | 1 weekend |
| Phase 1: Browser panels | Folders panel, thumbnails, star filter from XMP, filmstrip | 1–2 weekends |
| Phase 2: Basic panel | Lightroom's Basic panel minus Texture, Clarity and Dehaze; histogram; crop; undo | 2 weekends |
| Phase 3: Curves and LUTs | Tone curve per channel; `.cube` LUTs with previews and strength | 1–2 weekends |
| Phase 4: Export | JPEG, HEIC and TIFF export; signing and notarization | 1 weekend |
| v1.1 | Texture, Clarity, Dehaze as custom Metal kernels | — |
| v1.2 | Masks as layers: gradients, Vision subject and person masks, brush | — |
| Later | Writing ratings and labels, presets, iPad and iPhone app | — |

Not planned: healing, a catalog, cloud sync.
