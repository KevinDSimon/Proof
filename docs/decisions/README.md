# Decision records

Short records of choices that shape the project, so later work (by people or agents) knows why things are the way they are. One file per decision, numbered in order. A decision is changed by adding a new record that supersedes the old one, not by editing it.

Template:

```markdown
# NNNN. Title

Date: YYYY-MM-DD
Status: Accepted | Superseded by NNNN

## Context
What problem or question prompted this.

## Decision
What we chose.

## Consequences
What this makes easier, harder, or rules out.
```
